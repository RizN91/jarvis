# Screenshots

Every image here is a **real capture of the running application**, taken through
`CoreWebView2.CapturePreviewAsync` (the app's own surface) or the app's native
pill renderer. None of them is a mockup, and none is a grabbed desktop — so no
unrelated window, taskbar or wallpaper can appear in them.

Regenerate them yourself at any time:

```bat
.venv\Scripts\python.exe tests\test_reference_visuals.py   :: the wizard + pill
```

## The floating pill

Six states. The orb is deliberately larger than the bar and overflows it, and the
halo is a real radial bloom rather than a ring.

![The Jarvis pill in all six states](images/pill-states.webp)
