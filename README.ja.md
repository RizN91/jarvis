# Jarvis

**PC に話しかけるだけ。聞いて、答えて、あなたの代わりに打ち込みます。**

キーを押したまま話して、離すだけ — あなたの言葉が、いま前面にあるアプリの
カーソル位置にそのまま入ります。あるいは、本当に*仕事をする*音声会話を開くことも
できます。ウェブ検索、アプリの起動、マシン上でのタスク実行など。

サブスクリプション不要。OpenAI のキーはご自身のものをお使いください。
**1 分あたり $0.0045 から。**

## なぜ

タイピングより考えるほうが速い。しかも一日中、同じことを繰り返しています —
同じ形のメール、同じコミットメッセージ、同じ「この資料を要約して」という依頼。

音声入力ツールはその半分しか解決してくれません。しかもサブスクリプションだったり、
おもちゃだったり、黙って Enter を押して書きかけのメッセージを送信してしまったり。

Jarvis はその両方をこなし、費用はわずかで、邪魔をしません。サブスクリプションも、
アカウントも、テレメトリも、独自サーバーもありません。

## インストール

**Windows 10 または 11。** Python 3.11+ と OpenAI の API キーが必要です。

```bat
git clone https://github.com/RizN91/jarvis.git
cd jarvis
setup.cmd
```

`setup.cmd` は適切な Python を見つけ、仮想環境を作成し、固定された依存関係を
インストールして、スモークチェックを実行します。そのあと：

```bat
run.cmd
```

初回起動時にセットアップウィザードが開きます。マイク、スピーカー、ショートカット、
ウェイクワード、予算を順に確認し、API キーを尋ねます。キーは **Windows 資格情報
マネージャー**に保存され、ファイルには決して書き込まれません。

ウィザードを終えてディクテーションを始めるまで、どこにも何も送信されません。
例外は、自分で明示的に実行した接続テストだけです。

手動でセットアップする場合はこちら：

```bat
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m jarvis
```

## コスト

OpenAI のキーはご自身のものなので、OpenAI に直接支払います — 手数料なし、
サブスクリプションなし、席ごとのライセンスなし。エンジンは 2 つ、選ぶのは
あなたです：

| エンジン | モデル | コスト | 体感 |
| --- | --- | --- | --- |
| **Economy** *（ディクテーションの既定）* | `gpt-transcribe` | **$0.0045 / 分** | **1 ドルで約 27 時間**。逐語テキストの精度は最高 |
| **Live** | `gpt-live-1` | **$0.05 / 分** | 1 ドルで約 20 分。会話向きで、割り込みやターンにも対応 |

目安として：**1 日 20 分、週 5 日のディクテーションで、Economy なら月およそ
45 セント**です。高いのはアシスタント部分で、しかも実際に話しかけている間だけ
です。

Jarvis は自分の支出も計測し、設定した日次・月次の上限で停止します。この上限は
Jarvis 自身のカウンターです — OpenAI アカウントの予算を読むことはできませんし、
できるとも言いません。

## 機能

**ディクテーション**
- **あらゆる**アプリに入力 — エディタ、ブラウザ、チャット、ターミナル、
  チケットシステム。
- **Enter は絶対に押しません**。書きかけのメッセージを送信しようがありません。
- パスワード欄は拒否します。ターミナルでは自動入力せず、確認用にテキストを
  保持します。
- 独自の**ボキャブラリ** — 人名、専門用語、製品名 — をヒントとして文字起こしに
  渡し、精度を実測できるレベルで改善します。
- 自分の入力を飲み込まない取り消し。

**音声アシスタント**
- `Ctrl+Alt+Space` で会話を開きます。本物の割り込みに対応 — 話しかければ止まり
  ます。
- ツール層を通じてウェブ検索やマシン上の操作ができます。すべての操作に**あなたの
  明示的な「はい」**が必要で、引数がそのまま表示されます。
- ローカルのコーディングエージェント（Codex、Claude Code）に長い作業を任せられ、
  Jarvis はどれを使ったかを報告します。

**常に**
- **ローカルのウェイクワード** — 「Hey Jarvis」「Hey GPT」。お使いのマシン上で
  動作し（`sherpa-onnx`）、**ウェイクフレーズを待ち受けている間、音声はデバイスの
  外に出ません**。
- **ピル。** ピクセル単位のアルファを持つフローティングオーバーレイで、聞き取った
  内容と実行中の内容を表示します。本当にクリック透過で、アクティブ化も
  しません。
- **設計段階からのプライバシー** — テレメトリなし、クラウドデータベースなし、
  解析なし、アカウントなし。生の音声は保存しません。
- ライトテーマとダークテーマ。動きの抑制にも対応。

## あなたの言語に対応

セットアップと設定の UI 全体が **15 言語**で提供され、設定に切り替えがあります：

`English` · `Español` · `Français` · `Deutsch` · `Italiano` · `Nederlands` ·
`Polski` · `Português (BR)` · `Русский` · `Türkçe` · `العربية` (RTL) ·
`हिन्दी` · `中文 (简体)` · `日本語` · `한국어`

言語は初回起動時にシステムから検出されます。言語が足りない？ ファイル 1 つと
プルリクエスト 1 つで済みます — [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。

## 対応プラットフォーム

**Windows 10 と 11 を完全にサポートします。** コアは Win32 で作られています —
グローバル入力フック、`SendInput` によるテキスト挿入、ピル用のレイヤード
ウィンドウ、キー用の DPAPI、ロック/サスペンド検出用の WTS。ネイティブに感じられる
のはこのためで、まだ移植できない理由でもあります。

**macOS と Linux はまだ未対応です。** 実行するとトレースバックではなく、わかりやすい
メッセージを出して終了します。移植はロードマップにあり、フラグ一つではなく本格的な
プロジェクトです。

## 仕組み

短い説明です。詳しくは [ARCHITECTURE.md](ARCHITECTURE.md) にあります。

- 小さなトレイプロセスがグローバルフック、音声、ピルを担います。待機時は
  **2 プロセス、約 53 MB、1 コアの約 0.3 %**。
- 設定ウィンドウは**別**プロセスなので、WebView2（約 440 MB）は開いている間だけ
  存在します。
- 音声は WebSocket で OpenAI に直接送られます。**Jarvis のサーバーも localhost
  ポートもありません** — 攻撃対象も、落ちるものもありません。
- データ（履歴、ボキャブラリ、支出）は自分のディスク上の SQLite です。どこにも
  同期しません。

## セキュリティとプライバシー

- API キーは **Windows 資格情報マネージャーにのみ** DPAPI で保護して保存され、
  設定ファイル、データベース、ログ、コマンドライン、UI には決して書き込まれ
  ません。
- 秘匿化フィルターが、すべてのログレコードからキーらしき文字列を除去します。
- **テレメトリなし。解析なし。アカウントなし。**
- 生の音声はディスクに書き込みません。
- ログイン時の起動は任意で取り消し可能。アンインストールで完全に削除されます。

脆弱性の報告方法は [SECURITY.md](SECURITY.md) をご覧ください。

## コントリビュート

バグ報告、翻訳、テーマ、新しいツール動詞はすべて歓迎です — まず
[CONTRIBUTING.md](CONTRIBUTING.md) をどうぞ。テストスイート、言語の追加方法、そして
実際のバグを防いできたルール（ログに秘密情報を出さない、Enter を合成しない、
ディクテーション結果を命令にしない）が書かれています。

テストスイートは 13 の無料スイートにまたがる約 486 のアサーションで、モックではなく
実際のアプリケーションに入力します。手伝いたい人がいれば、やることはたくさん
あります。
